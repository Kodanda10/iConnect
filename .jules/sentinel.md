## 2024-04-06 - Prevent Prompt Injection in AI Greetings
**Vulnerability:** The Gemini AI prompt interpolation in `functions/src/greeting.ts` was directly using unsanitized user inputs (`request.name` and `request.leaderName`). This exposed the service to prompt injection, where a malicious user could craft an input with HTML tags or specific characters to manipulate the prompt behavior.
**Learning:** When using generative AI, any interpolated user inputs must be strictly sanitized. A naive HTML strip is insufficient if unclosed brackets remain. Additionally, if an input is stripped completely (e.g., if it was purely malicious), interpolating an empty string can break prompt grammatical structure. Falling back to the unsanitized string in such cases re-introduces the vulnerability.
**Prevention:** Aggressively sanitize user inputs intended for AI prompts by removing full HTML tags, standalone angle brackets (`<`, `>`), and control characters, while also truncating the length. If sanitization yields an empty string, fallback to a safe generic default string (like 'the constituent') instead of the original malicious input.
