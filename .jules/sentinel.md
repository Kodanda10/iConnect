## 2024-03-16 - Prompt Injection vulnerability in Gemini AI Greeting Service
**Vulnerability:** The `generateGreetingMessage` function in `functions/src/greeting.ts` passed raw, unsanitized user inputs (`name` and `leaderName`) directly into a prompt template for the Gemini AI model. This allowed prompt injection, where a user could input malicious text (e.g., control characters or `<script>` tags disguised as text or formatting) to alter the prompt's intended structure or behavior.
**Learning:** GenAI prompts are vulnerable to injection attacks if any part of the prompt is derived from untrusted user input. It is insufficient to assume inputs only contain standard text. When applying sanitization functions like `sanitizeInput` to optional user inputs, avoid falling back to the original unsanitized string (e.g., `sanitizeInput(name) || name`), as this re-introduces vulnerabilities if the malicious input is completely stripped.
**Prevention:** Always sanitize user-controlled data interpolated into Generative AI prompts (e.g., stripping control characters and HTML tags via `sanitizeInput`) prior to interpolation. If sanitization strips all content from a user input intended for an LLM prompt, fallback to a safe generic default string (like 'the constituent') to maintain the prompt's grammatical structure without reintroducing vulnerabilities.
