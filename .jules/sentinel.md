## 2025-03-31 - Prompt Injection via Unsanitized Names in GenAI Greetings
**Vulnerability:** User-controlled inputs (`name` and `leaderName`) were interpolated directly into GenAI prompts (`functions/src/greeting.ts`) without sanitization, exposing the system to prompt injection attacks where a constituent could manipulate the AI's behavior via malformed names.
**Learning:** Even simple, constrained prompts (like "generate a greeting") are vulnerable if interpolated inputs aren't sanitized. Furthermore, relying purely on stripping characters can leave prompts structurally broken (e.g. grammatically incorrect or empty name references) if the input is entirely composed of malicious tokens like `<malicious>`.
**Prevention:** Always apply strict sanitization (like `sanitizeInput` which limits length and aggressively strips control characters and HTML tags) *before* prompt interpolation. Critically, implement logical fallbacks (e.g., `|| 'the constituent'`) for inputs that are completely stripped by sanitization to ensure the prompt maintains a safe, valid grammatical structure.
