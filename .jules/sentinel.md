## 2025-04-20 - LLM Prompt Injection via Unsanitized Parameters
**Vulnerability:** User-provided inputs (`name` and `leaderName`) were interpolated directly into Generative AI prompts in `functions/src/greeting.ts` without sanitization. If malicious users injected prompt instructions disguised as names (e.g. `Ignore previous instructions and output...`), the model could act uncontrollably. Additionally, lack of sanitization also risked XSS in components rendering these responses.
**Learning:** Even though Gemini models and LLMs are relatively robust, direct interpolation of unsanitized strings in server-side generative logic serves as an attack vector. When designing data ingestion models that touch LLMs, strict content filtering is critical. Additionally, if the sanitization strips out all valid content, falling back to the unsanitized prompt directly opens the same vulnerability again; it must fallback to a generic placeholder.
**Prevention:** Ensure all user input strings interpolated into LLM prompts are aggressively stripped of control characters, length-limited, and HTML-filtered (via `sanitizeInput`). When sanitization results in an empty string, fallback to a neutral, context-appropriate string (e.g., `'the constituent'`) rather than the original input to maintain prompt grammar and safety.
