## 2025-03-15 - Fix Prompt Injection in Greeting Generation
**Vulnerability:** The Gemini AI prompt in `functions/src/greeting.ts` was interpolating user input (`request.name`, `request.leaderName`) directly into the prompt string without sanitization. An attacker could provide a malicious string containing HTML tags or control characters, potentially bypassing the prompt structure or causing injection.
**Learning:** To prevent prompt injection, any user-controlled data interpolated into Generative AI prompts must be sanitized (e.g., stripping control characters and HTML tags via `sanitizeInput`) prior to interpolation. Furthermore, if sanitization strips all content from a user input intended for an LLM prompt (e.g., it was purely malicious HTML), fallback to a safe generic default string (like 'the constituent') must be used to maintain the prompt's grammatical structure without reintroducing vulnerabilities.
**Prevention:** Always use `sanitizeInput` on user input before injecting it into AI prompts. Implement a safe fallback default if sanitization removes all content.
