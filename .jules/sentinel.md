## 2025-03-30 - Sanitize Generative AI inputs to prevent prompt injection
**Vulnerability:** User inputs (`request.name`, `request.leaderName`) in `generateGreetingMessage` were directly interpolated into Gemini AI prompts without sanitization, exposing the system to potential prompt injection, XSS if returned text is rendered as HTML, and malicious overriding of AI behavior.
**Learning:** Even when generating seemingly benign strings (like greetings), user-controlled data can contain commands (e.g. `<<<>>>`, `<script>`) that hijack the AI's generation. Furthermore, aggressively stripping content (like angle brackets) can result in empty strings. If an input becomes empty, falling back to the original string re-introduces the vulnerability, while using the empty string breaks the grammatical structure of the prompt.
**Prevention:** Always pass AI-bound user inputs through a rigorous sanitization function (like `sanitizeInput` which limits length to 100 and removes `[<>]`). When sanitization results in an empty string for required grammatical parts of a prompt (like a name), implement a safe, generic fallback string (e.g. `'the constituent'`) to maintain the prompt's integrity and safety.
