## 2024-12-16 - Prompt Injection Vulnerability in Greeting Service
**Vulnerability:** User-provided inputs (`name` and `leaderName`) were directly interpolated into a prompt for the Gemini AI in `functions/src/greeting.ts` without sanitization. This allowed prompt injection and potential XSS if the fallback templates were used to render untrusted input.
**Learning:** GenAI prompts are just as susceptible to injection attacks as SQL queries if untrusted user input is concatenated. Also, when sanitization strips all content from a malicious input intended for an LLM prompt, using a generic fallback (like 'the constituent') maintains the prompt's grammatical structure without reintroducing vulnerabilities.
**Prevention:** Any user-controlled data interpolated into Generative AI prompts must be sanitized (e.g., stripping control characters and HTML tags via `sanitizeInput`) prior to interpolation. If sanitization removes all input, use a safe static default string rather than the original unsanitized string.
