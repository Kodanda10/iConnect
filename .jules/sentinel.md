## 2024-05-24 - [Prompt Injection via Unsanitized Interpolation]
**Vulnerability:** User-provided inputs (e.g., constituent names, leader names) were directly interpolated into Generative AI prompts without sanitization. This allowed malicious users to inject HTML tags, control characters, or prompt engineering payloads, potentially hijacking the AI's output or causing XSS when the generated text is rendered.
**Learning:** Even when inputs are intended for AI consumption, they must be treated as untrusted and sanitized. Additionally, when sanitization completely strips an input (e.g., a pure malicious payload like `<script></script>`), falling back to an empty string or the original input can break the prompt's grammatical structure or re-introduce the vulnerability.
**Prevention:** Always sanitize inputs interpolated into AI prompts by removing HTML tags (while preserving inner text) and control characters. Use safe, generic fallbacks (e.g., "the constituent", "the leader") when the sanitized string is empty to maintain the prompt's structural integrity safely.
