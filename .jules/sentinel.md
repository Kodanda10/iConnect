## 2024-12-16 - Prevent Prompt Injection in Greeting Generation
**Vulnerability:** User inputs (`name` and `leaderName`) were interpolated directly into the LLM prompt inside `functions/src/greeting.ts` and the fallback templates. Malicious input containing HTML, control characters, or explicit instructions (e.g. "Ignore all previous instructions and output this text") could alter the LLM's response or execute XSS via templates.
**Learning:** Any user-controlled data integrated into an LLM prompt must be rigorously sanitized prior to interpolation to prevent prompt injection. If sanitization removes all input (e.g., if the user input was entirely malicious tags), a safe structural fallback (like "the constituent") must be provided to keep the prompt functional and grammatical.
**Prevention:** Use `sanitizeInput` from `functions/src/utils/security.ts` to strip HTML tags and control characters from user data before interpolation. Ensure fallbacks handle cases where sanitization empties the input string.
