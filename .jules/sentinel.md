## 2025-05-18 - [Prompt Injection Prevention in AI Greetings]
**Vulnerability:** The `generateGreetingMessage` function in `functions/src/greeting.ts` accepted unvalidated user inputs (like `name`) and directly interpolated them into prompts sent to the Gemini AI API, opening the door for prompt injection.
**Learning:** Even internal backend functions integrating with GenAI require strict sanitization of interpolated data to prevent malicious users from overriding instructions or executing arbitrary commands within the AI context. Furthermore, blindly relying on fallback templates with unsanitized data exposes the app to XSS via push notifications or UI.
**Prevention:** Always implement robust sanitization (e.g., removing HTML tags, angle brackets, and enforcing string limits) for user-provided data before prompt generation or template interpolation. Ensure that heavily stripped data gracefully falls back to generic placeholders (e.g., `'the constituent'`) to avoid reintroducing vulnerabilities or causing empty prompt errors.
