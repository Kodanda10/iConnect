## 2024-04-14 - Prevent Prompt Injection in LLM Greeting Generation
**Vulnerability:** The Gemini AI integration in `functions/src/greeting.ts` was interpolating user input directly into the prompt without sanitization. If malicious users injected arbitrary characters (like `<>`) or control characters, it could disrupt prompt parsing or lead to prompt injection where the model behaves contrary to the expected output.
**Learning:** All dynamically provided data from users must be aggressively sanitized before passing it to GenAI. Furthermore, we must account for the case where aggressive sanitization completely strips the provided input (e.g., if a user sends just `<script>`), which could result in a grammatical error in the prompt if we don't handle the empty string case with a generic fallback.
**Prevention:** Implement and use a robust sanitization function like `sanitizeInput` that aggressively removes angle brackets, control characters, and limits string length. When sanitizing optional inputs or inputs used directly in sentences, implement safe fallback logic (e.g. `const safeName = sanitizeInput(name) || 'the constituent'`) to maintain grammatical structure.
