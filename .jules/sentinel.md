## 2024-12-16 - Prevent Generative AI Prompt Injection and Grammatical Issues via Input Sanitization
**Vulnerability:** User-provided inputs (`name` and `leaderName`) were being interpolated directly into generative AI prompts (Gemini API) in `greeting.ts`, making the application vulnerable to prompt injection, where malicious input (e.g., HTML tags or control characters) could alter the instruction context or inject harmful content.
**Learning:** Sanitizing input using a method that removes HTML tags while preserving inner text mitigates XSS and injection attacks without unnecessarily blocking valid inputs containing residual text. Furthermore, if an input is completely composed of stripped tokens (like `<script></script>`) and evaluates to empty, falling back to the original unsanitized string re-introduces vulnerabilities.
**Prevention:** Always sanitize user-controlled data before interpolating it into LLM prompts using functions like `sanitizeInput` that strip control characters and HTML tags. When dealing with optional inputs, if sanitization entirely strips the content, fallback to a safe generic default string (like `'the constituent'`) to maintain prompt grammatical structure while avoiding reintroduction of vulnerabilities.
