## 2025-03-28 - XSS Defense-in-Depth for Generative AI Inputs
**Vulnerability:** User-controlled strings (like `name`, `ward`, `leaderName`) in `functions/src/greeting.ts` were interpolated directly into LLM prompts without sanitization. While LLMs are susceptible to natural-language prompt injection, stripping control characters and HTML tags provides a necessary defense-in-depth layer against XSS, especially if the generated greeting is later rendered in a browser.
**Learning:** In a context where inputs might be fully stripped (e.g. `<script></script>`), naive sanitization like `sanitizedName || name` reintroduces the malicious payload. It is critical to use fallback defaults (e.g., `'the constituent'`) if inputs are completely stripped.
**Prevention:** Always sanitize string inputs using `sanitizeInput` (which removes HTML tags and control characters), and apply secure fallbacks that maintain valid grammatical structures instead of reverting to unsanitized values.
