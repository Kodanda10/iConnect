## 2024-05-24 - Custom Calendar Accessibility Patterns
**Learning:** Custom calendar components built with `role="button"` for day cells do not support `aria-selected` validly. Additionally, proper screen reader support requires robust labeling and state indicators beyond basic ARIA labels.
**Action:** When building or modifying custom calendars, use `aria-pressed={true/false}` to indicate the selected date instead of `aria-selected` (unless strictly using a grid/gridcell paradigm). Use `aria-current="date"` for the current day, ensure day buttons have `aria-label`s announcing the full date string (e.g. "1 January 2024") instead of just the number, and apply `aria-haspopup="listbox"` with `aria-expanded` and correct `role="listbox"`/`role="option"` combinations for month/year dropdowns.
