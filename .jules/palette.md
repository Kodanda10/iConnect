## 2024-03-12 - Accessible Custom Calendars
**Learning:** Custom calendar components require an extensive and highly specific set of ARIA attributes. Simple interactive elements like dropdowns need `aria-haspopup` and `aria-expanded` attributes on toggles, with `role="listbox"` and `role="option"` on the dropdown contents. Calendar grids require detailed labelling, using full date strings for `aria-label`s on date buttons. Furthermore, because `role="button"` doesn't support `aria-selected`, `aria-pressed` must be used for selected dates, while `aria-current="date"` identifies the current "today" date.
**Action:** When creating or maintaining custom calendar implementations, refer back to these required attributes. Never assume a visual-only state is adequate; screen readers need full explicit text strings for context and state tracking.
