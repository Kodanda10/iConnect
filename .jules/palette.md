## 2024-12-14 - Accessible Custom Calendar Pattern
**Learning:** When building custom calendar components with `role='button'` elements for individual days, using `aria-selected` is invalid since it's not a `role='option'` or `role='tab'`. Screen readers handle this inconsistently. Instead, using `aria-pressed` effectively communicates the selected state of a date button. Furthermore, day buttons must have their `aria-label` format the full date string (e.g., "14 December 2024") instead of just relying on the visual number, providing necessary context for screen reader users navigating the grid.
**Action:** Always apply `aria-pressed` for selection states on custom interactive grid buttons and construct full contextual strings for their `aria-label`. Use `aria-current="date"` to indicate the current date.
