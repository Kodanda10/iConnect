## 2025-01-20 - Adding ARIA attributes to interactive custom components
**Learning:** Custom calendar components like `GlassCalendar` use generic tags (`div`, `button` with text-only contents like `23`, or chevron icons) that lack semantic context for screen readers. Buttons like left/right arrows need `aria-label`s. More complex structures, such as dropdown month/year selectors, require precise ARIA attributes to be announced correctly. Specifically, visual selection states (e.g., Tailwind background classes for 'selected' or 'current day') are completely invisible to screen readers without explicit ARIA state attributes like `aria-pressed`, `aria-selected`, or `aria-current`.
**Action:** When implementing custom interactive UI controls in React, explicitly connect visual state to ARIA state. Provide descriptive `aria-label`s for icon-only buttons. Use `aria-haspopup="listbox"` and `aria-expanded` on dropdown toggles, construct dropdown menus with `role="listbox"` and `role="option"`, use `aria-selected` for chosen options, `aria-current="date"` for today's date, `aria-pressed` for selected date buttons (since `role="button"` does not support `aria-selected`), and generate fully-qualified date strings (e.g., '1 January 2024') for day button `aria-label`s to support complete accessibility.
