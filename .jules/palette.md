# Palette Journal

## 2024-12-17 - Input with Right Action Pattern
**Learning:** The `glass-input-dark` class has fixed left padding (48px) for icons but lacks a variant for right-side actions (like password toggles).
**Action:** When adding right-side icons, use `pr-12` utility and absolute positioning (`right-4`). Ideally, create a `glass-input-action` variant in CSS later.
