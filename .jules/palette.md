## 2024-03-14 - GlassCalendar Accessibility Fixes
**Learning:** Custom UI components like the generic `GlassCalendar` often lack native HTML attributes needed for complete screen reader accessibility. Missing basic `aria-label`s on button interactions and dropdown states results in an opaque user experience for keyboard/assistive tool users. Specifically, standard date representations need clear string interpolations (e.g. '1 January 2024') rather than just rendering raw digits when acting as active interactable day elements.
**Action:** When creating or maintaining custom structural UI components (calendars, listboxes, comboboxes), always mandate `aria-haspopup`/`aria-expanded`/`role="listbox"` usage. Provide complete string descriptions for isolated data nodes (like calendar days) so that the user context is retained implicitly.
