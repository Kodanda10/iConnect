## 2024-12-17 - Calendar Component Accessibility
**Learning:** Custom grid-based calendars are often implemented with generic buttons (e.g., just displaying "15" for the day) without context. Screen reader users need explicit contextual labels that combine the month, day, and year, along with dynamic states like "Today" or "Has Event". Similarly, dropdowns masquerading as select inputs need `aria-expanded` and `role="option"` with `aria-selected` to function properly with assistive technologies.
**Action:** When building or auditing custom calendar components, ensure all interactive elements, particularly icon-only navigation, have explicit `aria-label`s, and that day cells provide full context (Month Day, Year) rather than just the day number. Use `aria-selected` to explicitly manage focus and selection state.
