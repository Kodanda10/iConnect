## 2024-03-21 - Calendar Button Accessibility with ARIA
**Learning:** Custom calendar day components built using `<button>` elements (without `role="gridcell"`) cannot properly use `aria-selected="true/false"`, as `role="button"` does not support `aria-selected` according to ARIA specifications. Using `aria-selected` on standard buttons can cause accessibility validators to flag errors and may lead to inconsistent screen reader behavior.
**Action:** Use `aria-pressed="true/false"` for calendar date buttons that act as toggles, or use the appropriate `role="gridcell"` if building a full ARIA calendar grid. Additionally, always provide the full date string in the `aria-label` (e.g., "1 January 2024") since the button text only contains the day number, which lacks context out of layout flow.
