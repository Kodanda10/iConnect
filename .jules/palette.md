## 2026-04-11 - GlassCalendar Accessibility
**Learning:** Custom interactive calendars require extensive ARIA attributes to function for screen readers. Dropdowns need `role='listbox'` and `role='option'` with `aria-selected`. Interactive days need `aria-label` with the full date, `aria-pressed` to indicate selection, and `aria-current='date'` for the current day. The `<button>` tag inherently handles basic keyboard interaction (Space/Enter), but standard visual cues (like 'today' dots or colored selection backgrounds) are completely hidden from screen readers without explicit ARIA definitions.
**Action:** Ensure any future custom UI controls (especially date pickers or select dropdowns) have corresponding ARIA equivalents for visual states (e.g., using `aria-pressed` instead of relying solely on Tailwind background color classes).
