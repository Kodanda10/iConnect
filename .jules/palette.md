## 2024-05-18 - Applying ARIA Attributes to Custom Calendar Components
**Learning:** For custom calendar components acting as dropdowns or lists (e.g., `GlassCalendar`), standard `<button>` elements require specific ARIA roles to be fully accessible. `role="listbox"` and `role="option"` should be applied to dropdown container and items respectively, and `aria-haspopup="listbox"` combined with `aria-expanded` should be on the toggle. For standard buttons used as selectable date cells, `aria-pressed` should be used instead of `aria-selected` (since standard buttons don't support `aria-selected` outside of specific composite widgets like grid/listbox), and `aria-current="date"` identifies the current day.
**Action:** When creating or maintaining custom date pickers or dropdowns, strictly enforce matching `role="listbox"`/`role="option"` pairings, and ensure interactive state is exposed using appropriate boolean ARIA attributes like `aria-pressed`, `aria-expanded`, and `aria-current`.
