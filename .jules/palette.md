## 2024-12-19 - Accessible ARIA attributes for custom Glassmorphism calendars
**Learning:** Custom UI components like `GlassCalendar` that look and act like interactive dropdowns and list boxes require comprehensive ARIA attribute patterns (`aria-haspopup="listbox"`, `aria-expanded`, `role="listbox"`, `role="option"`, `aria-current="date"`, and full date readouts for `aria-label`) so screen readers provide contextual feedback beyond simple button interactions.
**Action:** When building custom date pickers or complex dropdown menus instead of standard `<select>` or `<input type="date">`, immediately incorporate the `listbox`/`option` role pattern and dynamically update semantic `aria-*` attributes (`aria-expanded`, `aria-selected`, `aria-current`) for proper screen reader navigation.
