## 2024-12-17 - Custom Calendar Component ARIA Accessibility
**Learning:** Custom calendar components built with `div` or generic button grids lack native semantic roles and states for date selection. While standard lists use `aria-selected` with `role="listbox"`, `role="button"` (used for clickable dates) does not support `aria-selected`. Instead, it requires `aria-pressed` for the selection state and `aria-current="date"` to semantically indicate the current (today's) date to screen readers.
**Action:** Always apply `aria-pressed` (not `aria-selected`) for selected states on `role="button"` elements. Use `aria-current="date"` to identify "today" in custom date picker grids. Ensure dropdown toggles consistently implement `aria-haspopup` and `aria-expanded` and wrap dropdown item grids in `role="listbox"`.
