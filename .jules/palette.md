## 2024-04-07 - GlassCalendar Component Accessibility
**Learning:** Custom calendar components (`GlassCalendar`) need specific `aria` attributes for full accessibility. `aria-label`s on day buttons must provide the full date string (e.g., "7 April 2024") so screen readers announce the exact date, rather than just the number "7". Additionally, `aria-pressed` should be used for the selected date on `role="button"` elements because `aria-selected` is typically for `role="option"`. Dropdown menus require `role="listbox"`, `role="option"`, `aria-haspopup`, and `aria-expanded` attributes.
**Action:** When implementing or modifying custom calendar or date picker components, ensure full date strings are used in `aria-label`s for individual days, use `aria-pressed` for selection states on buttons, and provide proper `listbox` roles for dropdowns.
