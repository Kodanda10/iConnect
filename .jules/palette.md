## 2024-12-19 - Adding Full Accessibility to Custom React Calendars
**Learning:** Custom calendar components built with `div`s and `button`s require specific ARIA roles and properties to be accessible. Navigation buttons need `aria-label`s. Dropdown containers need `role="listbox"`, dropdown options need `role="option"`, and the toggles need `aria-haspopup="listbox"` and `aria-expanded={boolean}`. Day buttons cannot just have the day number as content; they require a full date string like "1 January 2024" in an `aria-label`. To indicate the current day, use `aria-current="date"`, and to indicate a selected day (since `role="button"` does not support `aria-selected`), use `aria-pressed`.
**Action:** When building or modifying custom UI components like calendars or dropdowns, ensure all interactive elements without text content have `aria-label`s, verify proper semantic `role` mapping for complex interactive patterns (like listboxes), and utilize state-indicative ARIA attributes (`aria-current`, `aria-expanded`, `aria-pressed`).
