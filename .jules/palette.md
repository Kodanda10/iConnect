## 2025-04-20 - Adding ARIA attributes to custom React calendar
**Learning:** Custom interactive components like calendars need deep ARIA integration. Specifically, visually selected states (using Tailwind classes) must have matching `aria-pressed` (for buttons) or `aria-selected` attributes, and `aria-current="date"` is crucial for the 'today' marker. Furthermore, raw date buttons should have human-readable `aria-label`s (e.g., '15 January 2024') instead of just '15', and dropdowns require `role="listbox"` with `role="option"` children to function correctly with screen readers.
**Action:** When reviewing or building custom React UI controls (like date pickers or complex dropdowns), proactively verify that all visual state changes (selected, current, expanded) are mirrored with appropriate ARIA attributes, and ensure icon-only navigation buttons always have descriptive `aria-label`s.
