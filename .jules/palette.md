## 2024-05-20 - Explicit ARIA states for custom UI controls
**Learning:** Custom interactive UI controls in React (like calendars or select dropdowns) must have explicit ARIA state attributes (such as `aria-pressed`, `aria-selected`, or `aria-current`) for their visual selection states to ensure screen reader accessibility.
**Action:** When implementing custom interactive UI controls, ensure visual selection states are accompanied by explicit ARIA state attributes.
