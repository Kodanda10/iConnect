## 2024-12-15 - ARIA attributes for custom React Calendars
**Learning:** When building custom interactive components like calendars using standard HTML elements (e.g., standard `div` grids and `button` cells), standard semantic roles alone are insufficient. Complex state like selected vs. today and popup month selectors require explicit `aria-pressed`, `aria-current="date"`, and standard `listbox`/`option` associations to provide proper context to screen readers, especially because `role="button"` elements cannot legally use `aria-selected` according to ARIA spec.
**Action:** When building interactive grids, dropdowns, or selectable items without native equivalents in React, ensure to map custom visual selection states directly to appropriate ARIA state attributes (`aria-pressed`, `aria-current`, `aria-expanded`).
