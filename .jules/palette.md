## 2025-02-18 - Custom Calendar Component Accessibility
**Learning:** Custom interactive UI controls like calendars or select dropdowns require specific ARIA attributes for screen reader accessibility. Visual selection states (e.g., Tailwind background classes for "selected" or "current day") must be accompanied by explicit ARIA state attributes. For day buttons `aria-pressed` should be used instead of `aria-selected` as `role="button"` doesn't support `aria-selected`.
**Action:** When implementing or modifying custom interactive components, always ensure visual states have corresponding ARIA equivalents (e.g., `aria-pressed`, `aria-selected`, `aria-current="date"`, `aria-haspopup="listbox"`, `aria-expanded`, `role="listbox"`, `role="option"`). For calendar day buttons, use full date strings in `aria-label` (e.g., "1 January 2024").
